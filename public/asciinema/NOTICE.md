# Homepage terminal demo assets

- `asciinema-player.min.js` and `asciinema-player.css`: asciinema-player 3.18.0, Apache-2.0. See [`LICENSE.txt`](./LICENSE.txt) and https://github.com/asciinema/asciinema-player.
- `pi-theme.css`: Pi terminal palette stylesheet, retrieved from https://pi.dev/asciinema/pi-theme.css.
- `../recordings/default.cast.data`: gzip-compressed homepage terminal recording from https://pi.dev/recordings/default.cast. It is decompressed in the browser before playback.
