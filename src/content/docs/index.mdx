---
title: Pi
description: Pi 是一个极简的 agent harness。让工作流适应 Pi，而不是反过来。
---

<div class="section" data-story-index="0">
  <p class="section-label">01 / 可定制</p>
  <h2 class="section-title">改动 harness，而不是工作流</h2>
  <p>Pi 不是一个封闭的产品。需要一个命令、工具、Provider、工作流或者 UI 调整？让 Pi 现场为自己构建并修改。</p>
  <p>让 Pi 就地修改扩展，运行 <code>/reload</code> 后继续工作。觉得有用，就分享给其他人。</p>
</div>

<div class="section" data-story-index="1">
  <p class="section-label">02 / 模型选择</p>
  <h2 class="section-title">15+ 个 Provider，数百种模型</h2>
  <p>支持 Anthropic、OpenAI、Google、Azure、Bedrock、Mistral、Groq、xAI、Ollama 等服务，可通过 API Key 或 OAuth 认证。</p>
  <p>使用 <code>/model</code> 或 <code>Ctrl+L</code> 在会话中切换模型，也可以用 <code>Ctrl+P</code> 循环切换收藏模型。</p>
</div>

<div class="section" data-story-index="2">
  <p class="section-label">03 / 会话历史</p>
  <h2 class="section-title">树状、可分享的历史记录</h2>
  <p>会话以树形结构保存。使用 <code>/tree</code> 回到任意历史节点继续，所有分支都保存在同一个文件中。</p>
  <p>通过 <code>/export</code> 导出 HTML，或用 <code>/share</code> 生成可分享的链接。</p>
</div>

<div class="section" data-story-index="3">
  <p class="section-label">04 / 上下文工程</p>
  <h2 class="section-title">掌控上下文，而非被上下文限制</h2>
  <p>极简的系统提示词与可扩展性，让你掌控哪些信息进入上下文窗口，以及如何管理它们。</p>
  <p><code>AGENTS.md</code>、<code>SYSTEM.md</code>、压缩策略、Skills 与动态上下文注入，都可以按项目定制。</p>
</div>

<div class="section" data-story-index="4">
  <p class="section-label">05 / 实时引导</p>
  <h2 class="section-title">引导当前任务，或排队后续任务</h2>
  <p>Agent 工作时也可以继续发送消息。按 <code>Enter</code> 立即引导当前运行，按 <code>Alt+Enter</code> 将后续任务加入队列。</p>
</div>

<div class="section" data-story-index="5">
  <p class="section-label">06 / 多种运行方式</p>
  <h2 class="section-title">交互、脚本、RPC 与 SDK</h2>
  <p>使用完整终端 UI 进行交互；使用 print/JSON 模式运行脚本；通过 RPC 控制独立 Pi 进程；或者通过 SDK 将 Pi 嵌入应用。</p>
</div>

<div class="section" data-story-index="6">
  <p class="section-label">07 / 原语，而非功能</p>
  <h2 class="section-title">构建你自己的工作流</h2>
  <p>Extensions 是 TypeScript 模块，可访问工具、命令、快捷键、事件和完整 TUI。你可以自己实现 sub-agents、plan mode、权限门禁，或安装社区的 Pi 包。</p>
</div>
